# CityChat · แสนสุข

Interactive single-page summary of the latest Saensuk household-registry geocoding result for non-technical municipal officers and executives.

The public page intentionally contains aggregate figures only. Do not commit the raw master table, household identifiers, house numbers, parcel identifiers, owner-address evidence, or exact per-house coordinates to this repository.
